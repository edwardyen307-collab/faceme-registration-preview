註冊表單

此為靜態預覽：姓名與照片僅在本機瀏覽器暫存顯示，不會上傳、不會呼叫 FaceMe API、不會持久儲存。 請勿輸入真實個資或上傳真實人臉照片。
必填。預覽環境請使用假名。
必填。請從清單選擇現有群組，或輸入新名稱（新名稱會先 create 再以官方 groupId 匯入）。不送 tags／skipQC／forceImport。

新群組需指定顏色與圖示編號（Central create 必填；不送 type）。

可從相簿選擇，或在支援的手機上直接開啟相機拍攝。圖片僅以本機 Object URL 顯示縮圖，不會外傳。 接受 JPG／PNG／WebP／HEIC，上限 8MB。

管理／設定（僅本機） （預設收合，點此展開）

① 瀏覽器→薄後端；② 薄後端→Central。變更 API base 會清除同意狀態。

① 瀏覽器 → 薄後端（API base）

存在 localStorage。姓名／照片只當次送到薄後端，前端不持久保存。GitHub Pages 無法打本機／Central。


          


          
② 薄後端 → FaceMe Central（FACEME_BASE_URL）

          

            寫入伺服器 .env 的 Central 位址（僅 https://主機或IP[:埠]）。帳密仍只在 .env，網頁不會顯示或讀取密碼。
          

          
此區塊僅本機版（127.0.0.1）可用；GitHub Pages 無法修改 Central。

          
          

            
            
            
          


          

          

            
            

              僅當 Central 是 127.0.0.1／localhost／::1 時可開啟。有中間人風險；正式環境請匯入 CA。寫入 .env 的 FACEME_SKIP_TLS_VERIFY，立即生效。
            

            

          

          


          

            
③ 手機連線（區網，預設關閉）

            
            

              僅能從本機（127.0.0.1）開關。開啟後伺服器改聽區網，手機用 http://電腦區網IP:埠/ 開啟（Safari 用 HTTP 即可，拍照不需 HTTPS）。設定與 .env 仍只准本機修改。第一次開啟時 Windows 可能跳出「Windows 安全性警訊」，請只允許「私人網路」，不要勾選「公用網路」。用完請關閉。
            

            

            

            

          

          
測試讀取群組

          
診斷用。註冊表單會在開啟時自動載入群組清單，不必按此按鈕。

          

            
          

          

          

            
找人／補群組

            
用來找出可能被移出群組後「失踪」的人，再補回群組。讀取不必開真實寫入；指定群組會寫入 Central，需雙旗標與確認。僅本機 127.0.0.1。


            
列出未分群組的人

            
呼叫 member/list 且不帶 groupId（Central 是否會回未分組的人，尚未實測）。

範圍掃描（只讀）

            
依序查詢編號 A 到 B（一次最多 200 個，略過不存在的編號），列出未分組／狀態不明的人。

            

              
              
              
            

            

            


            
指定群組（寫入 Central）

            
對查到的人呼叫 person/update，只送 personId 與 groupId。需 FACEME_REAL_MODE 與法務確認皆為 1。
